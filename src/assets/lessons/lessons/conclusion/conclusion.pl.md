# Podsumowanie i kolejne kroki

Gratulacje! Zbudowałeś od zera kompletne RESTful API przy użyciu Pythona i Flask. Masz teraz w pełni funkcjonalną aplikację **My DIY Library**, która potrafi tworzyć, odczytywać, aktualizować i usuwać książki.

---

## Co udało Ci się osiągnąć

Nauczyłeś się i wdrożyłeś:

* Konfigurację środowiska programistycznego Python z wykorzystaniem środowisk wirtualnych
* Zrozumienie podstaw backendu i sposobu działania interfejsów API
* Tworzenie aplikacji Flask z trasami (routes)
* Pracę z bazami danych SQLite przy użyciu SQLAlchemy
* Implementację pełnych operacji CRUD (Create, Read, Update, Delete)
* Dodawanie walidacji danych i obsługi błędów
* Testowanie swojego API za pomocą programu Postman

## Funkcje Twojego API

Twoja biblioteka DIY potrafi:

* Tworzyć nowe książki za pomocą żądań POST
* Pobierać wszystkie książki lub konkretną książkę za pomocą żądań GET
* Aktualizować informacje o książkach za pomocą żądań PUT
* Usuwać książki za pomocą żądań DELETE
* Wyszukiwać książki według tytułu lub autora
* Walidować dane wejściowe i zwracać pomocne komunikaty o błędach

---

## Co dalej?

Teraz, gdy masz już działające API, oto kilka sposobów na poszerzenie swojej wiedzy:

### Rozbuduj swoje API

* Dodaj uwierzytelnianie użytkowników (authentication), aby zabezpieczyć swoje punkty końcowe (endpoints)
* Zaimplementuj stronicowanie (pagination) dla dużych zbiorów danych
* Dodaj opcje sortowania (według tytułu, autora lub roku wydania)
* Stwórz relacje między książkami a innymi encjami
* Wdróż ograniczanie liczby żądań (rate limiting), aby zapobiec nadużyciom

### Ulepsz swój kod

* Użyj Flask blueprints dla lepszej organizacji kodu
* Dodaj zarządzanie konfiguracją za pomocą zmiennych środowiskowych
* Zaimplementuj logowanie (logging) do śledzenia użycia API i błędów
* Napisz testy automatyczne
* Dodaj dokumentację API za pomocą Swagger/OpenAPI
* Poeksperymentuj z produkcyjną bazą danych, taką jak PostgreSQL

### Wdróż swoje API

* Wdróż aplikację na platformie chmurowej
* Skonfiguruj produkcyjną bazę danych
* Dowiedz się, jak działają serwery produkcyjne
* Poznaj procesy ciągłego wdrażania (continuous deployment)
* Dodaj monitorowanie i śledzenie błędów

## Połącz swój backend

Backend jest już kompletny.

Aby pomóc Ci zobaczyć efekty Twojej pracy w akcji, ten kurs zawiera gotową aplikację frontendową, która została już zaprojektowana dla tego projektu.

Twoim zadaniem jest po prostu połączenie swojego backendu z frontendem.

Pozwoli Ci to na:

- Zobaczenie swoich książek wyświetlanych w prawdziwej aplikacji
- Tworzenie książek za pomocą interfejsu użytkownika
- Edytowanie książek bez użycia programu Postman
- Usuwanie książek za pomocą kliknięcia przycisku
- Doświadczenie tego, jak aplikacje frontendowe i backendowe współpracują ze sobą

W tym momencie frontend powinien działać z punktami końcowymi API, które utworzyłeś w trakcie kursu.

Jeśli coś nie działa, potraktuj to jako ćwiczenie z debugowania:

- Sprawdź adresy URL swoich tras
- Zweryfikuj metody HTTP
- Porównaj formaty żądań i odpowiedzi
- Przejrzyj komunikaty o błędach
- Przetestuj punkt końcowy w programie Postman

Programowanie w świecie rzeczywistym często polega na łączeniu ze sobą istniejących systemów, a to świetna okazja do przećwiczenia tej umiejętności.
