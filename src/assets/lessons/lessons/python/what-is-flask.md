# What is Flask?

Flask is a micro web framework written in Python. It is classified as a microframework because it does not require particular tools or libraries. Other than Werkzeug, anIterable WSGI utility library, and Jinja 2, a templating engine, Flask does not bundle any additional libraries. This makes it lightweight and allows developers to have control over their project.

### Key features

- **Micro**: Flask is very small and lightweight, making it easy to understand and modify.

- **Flexible**: Flask is designed to be flexible and easy to extend. It makes it easy to add new functionality to your application.

- **Lightweight**: Flask is lightweight and easy to use. It has a small footprint and is designed to be used in small to medium-sized applications.

- **Templating engine**: Flask can be used with Jinja2, a powerful templating engine that allows you to generate HTML output securely from Python code.

- **Routing**: Flask provides a simple and intuitive way to define routes for your application.

- **Support for HTTP methods**: Flask provides methods to handle various HTTP methods such as GET, POST, PUT, DELETE, etc.

### Popularity

Flask is a popular choice for web development in Python. It is often used for small to medium-sized web applications and is known for its simplicity and ease of use.

### Syntax

Flask uses a simple syntax that is easy to read and understand. It uses decorators to define routes and request handlers.
