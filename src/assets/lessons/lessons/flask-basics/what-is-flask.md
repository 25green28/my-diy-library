# What is Flask?

Flask is the web framework we're using to build our My DIY Library. It's a Python library that makes it easy to create web applications and APIs.

## What is a web framework?

Think of a framework like a toolkit or a set of pre-made building blocks. Instead of building everything from scratch, you use the framework's tools to assemble your application. Flask provides the basic structure and tools you need to handle web requests, respond to users, and manage data.

## Why are we using Flask?

Flask is perfect for beginners and for building APIs because:

- **Simple to learn**: You can understand the basics quickly
- **Lightweight**: It doesn't force you to use any specific way of doing things
- **Flexible**: You can add only the features you need
- **Perfect for APIs**: It's designed to work well for building RESTful APIs like ours
- **Popular**: There's lots of documentation and community support

## Flask vs other frameworks

There are other Python web frameworks like Django. Django is more powerful and comes with many built-in features, but it's also more complex. Flask is simpler and gives you more control, which makes it great for learning and for smaller projects like our My DIY Library.

## Core Flask concepts

Flask is built around a few key ideas:

- **Routes**: These are URL patterns that tell Flask which function to run when someone visits a specific URL
- **Requests and responses**: Flask handles incoming web requests and helps you send responses back
- **Extensions**: You can add extra functionality like database support through extensions

## When should you use Flask?

Flask is great for:
- Building REST APIs (like our book management system)
- Small to medium web applications
- When you want flexibility and simplicity
- Learning web development

In this project, Flask will handle all the web communication for our My DIY Library.
