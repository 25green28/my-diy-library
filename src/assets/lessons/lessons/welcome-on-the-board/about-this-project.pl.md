# O projekcie i o mnie

Cześć! Nazywam się Mateusz Laski *(25green28)* i witam Cię w projekcie **My DIY Library**!

Stworzyłem ten projekt, aby zapewnić przyjazne dla początkujących wprowadzenie do tworzenia aplikacji serwerowych (backend development). Zamiast skupiać się wyłącznie na teorii, wspólnie zbudujemy prawdziwą aplikację, ucząc się poszczególnych koncepcji dokładnie wtedy, gdy będą nam potrzebne.

Moim celem jest pomóc Ci zrozumieć nie tylko *jak* zbudować backend, ale także *dlaczego* pewne rzeczy działają w określony sposób. Ten projekt to praktyczny samouczek, który poprowadzi Cię krok po kroku przez proces tworzenia kompletnego interfejsu API od zera przy użyciu języków **Python** i frameworku **Flask**. W trakcie tego kursu stworzysz API zdolne do zarządzania biblioteką książek poprzez dodawanie, odczytywanie, aktualizowanie i usuwanie rekordów.

---

## Co zbudujesz

Do końca tego projektu stworzysz w pełni funkcjonalne API, które potrafi:

- Przechowywać informacje o książkach w bazie danych
- Dodawać nowe książki do Twojej biblioteki
- Pobierać pojedyncze książki lub całe ich listy
- Aktualizować szczegółowe dane książek
- Usuwać książki z biblioteki
- Wyszukiwać książki według tytułu lub autora

## Czego się nauczysz

Ten projekt został zaprojektowany z myślą o osobach początkujących i wprowadza w świat backendu poprzez praktyczne przykłady.

Nauczysz się:

- Jak skonfigurować środowisko programistyczne Pythona
- Czym jest backend i jak dokładnie działa
- Jak budować interfejsy API za pomocą frameworku Flask
- Jak pracować z bazami danych SQLite
- Jak wdrażać operacje CRUD (**C**reate, **R**ead, **U**pdate, **D**elete)
- Jak walidować i testować żądania do API

## Wymagania wstępne

Nie jest wymagane żadne wcześniejsze doświadczenie w pracy z backendem.

Potrzebujesz jedynie:

- Komputera z systemem Windows, macOS lub Linux
- Podstawowej umiejętności korzystania z przeglądarki i zarządzania plikami
- Ciekawości oraz chęci do nauki

---

## Zanim zaczniemy

Nie martw się, jeśli niektóre z powyższych terminów brzmią dla Ciebie obco. Pojęcia takie jak API, bazy danych, trasy (routes) czy operacje CRUD będą wprowadzane stopniowo i szczegółowo wyjaśniane na każdym etapie projektu.

> **Wskazówka:** Jeśli kiedykolwiek poczujesz, że utknąłeś, pamiętaj, że to całkowicie normalne. Nauka backendu wymaga praktyki, a popełnianie błędów jest nieodłączną częścią tego procesu.
