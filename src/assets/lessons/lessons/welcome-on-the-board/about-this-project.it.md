# Informazioni su questo progetto e su di me

Ciao! Sono Mateusz Laski *(25green28)* e ti do il benvenuto in **My DIY Library**!

Ho creato questo progetto per offrire un'introduzione allo sviluppo backend che sia adatta ai principianti. Invece di concentrarci solo sulla teoria, struttureremo insieme un'applicazione reale e impareremo i vari concetti man mano che ne avremo bisogno.

Il mio obiettivo è aiutarti a capire notevolmente non solo *come* si costruisce un backend, ma anche *perché* le cose funzionano in un determinato modo. Questo progetto è un tutorial pratico che ti guiderà nella creazione da zero di una API backend completa utilizzando **Python** e **Flask**. Durante il corso, svilupperai un'API in grado di gestire una libreria di libri consentendo di aggiungere, leggere, aggiornare ed eliminare i record.

---

## Cosa andrai a costruire

Alla fine di questo progetto, avrai a disposizione un'API completamente funzionale in grado di:

- Memorizzare le informazioni dei libri all'interno di un database
- Aggiungere nuovi libri alla tua libreria
- Recuperare singoli libri o elenchi completi di libri
- Aggiornare i dettagli dei libri
- Eliminare i libri dalla libreria
- Cercare i libri in base al titolo o all'autore

## Cosa imparerai

Questo progetto è stato pensato per chi parte da zero e introduce lo sviluppo backend attraverso esempi pratici.

Imparerai a:

- Configurare un ambiente di sviluppo Python
- Capire cos'è un backend e come funziona nel dettaglio
- Costruire delle API utilizzando il framework Flask
- Lavorare con i database SQLite
- Implementare le operazioni CRUD (**C**reate, **R**ead, **U**pdate, **D**elete)
- Convalidare e testare le richieste dirette alle API

## Prerequisiti

Non è richiesta alcuna esperienza precedente nello sviluppo backend.

Hai solo bisogno di:

- Un computer con sistema operativo Windows, macOS o Linux
- Familiarità di base con l'uso del browser e la gestione dei file sul computer
- Curiosità e tanta voglia di imparare
